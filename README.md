# 🚗 YO'LDA — O'zbekiston Mashinalari

O'zbekiston avtobozorida eng ko'p tarqalgan mashinalarning texnik xususiyatlari va narxlari haqida ma'lumot beruvchi statik web-sayt.

🔗 **Jonli sayt:** [islombek-create.github.io/uzbek-cars-site](https://islombek-create.github.io/uzbek-cars-site/)

---

## 📋 Loyiha haqida

Sayt UzAuto Motors ishlab chiqaradigan 6 ta keng tarqalgan modelni (Nexia 3, Cobalt, Onix, Tracker, Malibu 2, Damas) taqdim etadi — har biri uchun dvigatel, quvvat, uzatmalar qutisi, yoqilg'i sarfi va boshlang'ich narx ko'rsatilgan. Shuningdek, barcha modellarni bitta jadvalda solishtirish imkoniyati mavjud.

## ✨ Xususiyatlar

- 🎨 **Zamonaviy dizayn** — avtomobil mavzusiga mos qorong'i tema va aniq tipografika
- 📊 **Solishtirish jadvali** — barcha modellarni yonma-yon ko'rish
- 📱 **To'liq responsive** — telefon, planshet va kompyuterda bir xil yaxshi ko'rinadi
- ♿ **Qulaylik (accessibility)** — klaviatura orqali navigatsiya, kamaytirilgan animatsiyaga hurmat
- ⚡ **Yengil va tez** — hech qanday tashqi kutubxona yoki JavaScript yo'q

## 🛠️ Ishlatilgan texnologiyalar

| Texnologiya | Maqsad |
|---|---|
| 🧱 **HTML5** | Sayt tuzilishi va kontent |
| 🎨 **CSS3** | Dizayn, layout (Grid/Flexbox), responsive media query'lar |
| 🔤 **Google Fonts** | Oswald va Manrope shriftlari |
| 🐙 **Git & GitHub** | Versiyalarni boshqarish |
| 🌐 **GitHub Pages** | Bepul hosting |
